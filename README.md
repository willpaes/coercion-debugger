# Type Coercion Debugger in JavaScript 🐛

A lightweight JavaScript demonstration focused on identifying, isolating, and fixing type coercion bugs and arithmetic evaluations in JavaScript applications.

## 📌 Features

✅️ Addition & Subtraction Checks: Demonstrates standard integer additions and subtractions to prevent accidental string concatenation bugs;

✅️ Zero & Single-Digit Handling: Validates mathematical consistency when operating with edge values like 0;

✅️ Multiplication & Repeat Operations: Tests basic arithmetic multiplication alongside repeated value sums to ensure strictly typed numeric outputs.

### 🚀 🛠️ Usage

You can run this project locally using Node.js or inside your browser's developer console.

### Running with Node.js

Ensure you have Node.js installed.

### Clone this repository:

git clone https://github.com/willpaes/coercion-debugger.git


### Navigate to the project directory:

cd coercion-debugger


### Execute the script:

node index.js


### 📋 Output

5 + 10 = 15

8 - 5 = 3

1 + 5 = 6

0 + 8 = 8

10 * 2 = 20

11 + 11 = 22
